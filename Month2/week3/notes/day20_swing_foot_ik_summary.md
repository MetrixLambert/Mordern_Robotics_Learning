# ROBO_Learn · Month 2 Day 20 学习总结

**主题**：摆动足轨迹、分段五次多项式、二维二连杆 IK  
**状态**：已完成；依据用户提交的 Python 实现与结果图（2026-11-17）

## 1. 任务与坐标约定

给定摆动脚的初末位置、持续时间和最高离地高度，生成足端参考位置，并通过平面二连杆逆运动学转化为关节角。

- 世界系：$x$ 向前、$z$ 向上，地面 $z=0$。
- 固定髋关节位置 $p_{hip}=(0,0.75)$ m。
- 大腿、小腿长度 $l_1=l_2=0.42$ m。
- 足端从 $(-0.12,0)$ m 移至 $(0.18,0)$ m，时间 $T=0.5$ s，最大离地高度 $h=0.10$ m。
- 关节角采用标准平面 2R 机械臂约定，不是某特定机器人实际电机零位角。

## 2. 五次插值与边界条件

归一化时间 $s=t/T$。五次插值：

$$\alpha(s)=10s^3-15s^4+6s^5.$$

满足 $\alpha(0)=0,\alpha(1)=1$，且首末一阶、二阶导数都为零。

水平轨迹：

$$x(t)=x_0+(x_f-x_0)\alpha(t/T).$$

竖直轨迹采用分段五次：

$$z(t)=\begin{cases}h\alpha(2t/T),&0\le t\le T/2,\\h[1-\alpha(2t/T-1)],&T/2<t\le T.\end{cases}$$

起点、最高点和终点的速度与加速度均为零，轨迹在分段连接点至少为 $C^2$，但 jerk 一般不连续。非零触地速度也可以是其他动态步行方案的合理选择；此处按练习目标取零。

## 3. 平面二连杆 IK 与 FK

先将足端世界坐标转成髋关节相对坐标：

$$[x_H,z_H]^T=p_{foot}^W-p_{hip}^W.$$

$$\cos q_2=\frac{x_H^2+z_H^2-l_1^2-l_2^2}{2l_1l_2},$$

$$q_1=\operatorname{atan2}(z_H,x_H)-\operatorname{atan2}(l_2\sin q_2,l_1+l_2\cos q_2).$$

足端可达必要条件：

$$|l_1-l_2|\le\sqrt{x_H^2+z_H^2}\le l_1+l_2.$$

用户实现了可达性检查、解析 IK 和独立 FK，$FK(IK(p))$ 曲线与期望足端轨迹重合。用户采用 $q_2=+\arccos(\cdot)$，与练习建议的负分支不同，但数学上是有效的另一 IK 分支。实际机器人必须按膝关节允许弯曲方向与限位选择分支。

## 4. 实验图与验证

- 足端轨迹呈单峰抬脚弧线，峰值约 $0.10$ m；水平前摆 $0.30$ m。
- 位置、速度、加速度曲线满足设定的端点行为。
- 关节角曲线连续，FK 重构足端轨迹与期望轨迹在图上重合。
- `np.gradient` 对离散位置两次求导，端点加速度估计有误差；断言中的阈值是本实验的数值容差，不是通用物理标准。严格验证可使用解析导数。

## 5. 四道思考题

1. **FK(IK) 验证**：检查 IK 求出的关节角确实能实现目标足端位置；但并不验证力矩、碰撞或动力学可行性。
2. **髋关节移动**：世界坐标下目标足轨迹可以不变，但世界系到髋关节系的变换随时间变化，IK 的输入和关节角轨迹会改变。髋部旋转时还需旋转变换。
3. **不可达目标**：盲目 `clip(cos_q2)` 会掩盖真正的不可达性，使 FK 无法重现指定足端目标；微小舍入误差可在合理容差内裁剪。
4. **足端平滑不保证力矩平滑**：$\tau=M(q)\ddot q+C(q,\dot q)\dot q+g(q)$，IK 近奇异点会放大关节运动；接触切换也可能造成力矩变化。在平滑非奇异模型和固定 IK 分支下，$C^2$ 关节轨迹通常可产生连续逆动力学力矩，不能笼统断言必然不连续。

## 6. 工程局限与后续
